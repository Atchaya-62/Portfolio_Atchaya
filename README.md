# Interactive Portfolio Website

An interactive portfolio website for an AI & Data Science student, featuring premium aesthetics, smooth animations, and multiple theme modes.

## Tech Stack

- **Frontend Framework:** React 18+ with TypeScript
- **Build Tool:** Vite
- **Styling:** Tailwind CSS + CSS Modules
- **Animations:** Framer Motion
- **Routing:** React Router
- **Form Management:** React Hook Form + Zod
- **Testing:** Vitest + React Testing Library + fast-check (PBT)

## Getting Started

### Prerequisites

- Node.js 18+ and npm

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

### Build

```bash
npm run build
```

### Testing

```bash
# Run tests once
npm test

# Run tests in watch mode
npm run test:watch

# Run tests with UI
npm run test:ui
```
